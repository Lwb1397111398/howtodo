# 模块总览索引

「工作如何做」（HowTodo）Android 应用（包名 `com.howtodo`，Kotlin + Jetpack Compose + Room）的功能模块划分。每个模块一份总览文件，按「从哪来 → 怎么处理 → 产出什么 → 影响谁」讲清运作流程。

| 模块 | 一句话职责 | 总览文件 |
| --- | --- | --- |
| 应用自更新 | 启动静默检查 + 设置页手动检查 GitHub Release 新版本，下载 APK 并唤起系统安装器覆盖安装；推送代码后云端自动出包发版 | [应用自更新模块总览.md](应用自更新模块总览.md) |
| 界面导航（ui/） | Compose 界面层：今天/项目/资料/知识/聊天/设置各屏 + 路由 | [界面模块总览.md](界面模块总览.md) |
| AI 调用层（ai/） | LLM 客户端与路由：按角色绑定模型、JSON 抽取、补丁生成、令牌预算 | 待补充 |
| 数据层（data/） | Room 数据库（AppDatabase/Daos/Entities）与各领域 Repo（项目、任务、提案、提醒、供应商等） | [数据层模块总览.md](数据层模块总览.md) |
| 材料导入（ingest/） | 分享/选图/文档导入：PDF、Office、RTF 解析、分块、视觉 OCR、入库队列 | [材料导入模块总览.md](材料导入模块总览.md) |
| 提醒通知（notify/） | 精确闹钟调度、每日早报 Worker、通知渠道、开机/改时间重建 | 待补充 |
| 检索增强（rag/） | 本地 BM25 式检索 + LLM 回答（知识问答） | 待补充 |
| 工具（util/） | 私有目录存储布局、API Key 的 Keystore 加密（Crypto）、备份导出/导入、格式化 | 待补充 |
| 依赖容器（di/） | 手写 AppContainer：集中构造并暴露全部单例（含 updateManager） | 待补充 |
| 应用入口（App/MainActivity/ShareActivity） | Application 启动初始化（渠道、每日任务、静默检查更新）；分享/打开文件入口 | 待补充 |
